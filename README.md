##  Projet Principal : Ghazaléa

<div align="center">

### E-commerce Full Stack en Production

🌐 **[Voir le site live](https://ghazalea.com)** · 📡 **[Tester l'API](https://ghazalea-backend-production.up.railway.app/api/products)**

[![Backend CI](https://github.com/ghazalsoltani/ghazalea-backend/actions/workflows/ci.yml/badge.svg)](https://github.com/ghazalsoltani/ghazalea-backend/actions)
![Symfony](https://img.shields.io/badge/Symfony-7.x-000000?style=flat&logo=symfony)
![React](https://img.shields.io/badge/React-18-61DAFB?style=flat&logo=react)
![Stripe](https://img.shields.io/badge/Stripe-Integrated-635BFF?style=flat&logo=stripe)

</div>

Une application e-commerce complète démontrant une architecture moderne découplée et déployée en production :

| 🔧 Backend (Symfony) | 🎨 Frontend (React) | ⚙️ DevOps |
|---------------------|---------------------|-----------|
| API REST (15+ endpoints) | React 18 + TypeScript | Docker containerization |
| JWT Authentication | Context API state | GitHub Actions CI/CD |
| Stripe Payments | Multi-step checkout | Railway + Vercel deploy |
| Symfony Messenger (async) | Responsive Tailwind | Automated testing |
